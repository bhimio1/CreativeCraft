atelier-cli — the Atelier hub without a window

USAGE
  atelier-cli list [--json]          every app and its status
  atelier-cli install <app>...       install, or update to the latest release
  atelier-cli remove <app>...        uninstall
  atelier-cli open <app> [files...]  open an app
  atelier-cli sync [--preview]       sync the projects folder with cloud storage
  atelier-cli login | logout         sign in to / out of Google Drive
  atelier-cli mcp                    serve MCP on stdio for AI assistants

Settings live in the config folder (settings.json). ATELIER_HOME=<dir> keeps all data in one
folder. GITHUB_TOKEN raises GitHub's download-API rate limit.
