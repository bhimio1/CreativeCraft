creativecraft-cli — the CreativeCraft hub without a window

USAGE
  creativecraft-cli list [--json]          every app and its status
  creativecraft-cli install <app>...       install, or update to the latest release
  creativecraft-cli install <app> --fork <owner/name>          …from a fork's releases (remembered)
  creativecraft-cli install <app> --git [url] [--branch <b>]   …built from git with cargo (remembered)
  creativecraft-cli install <app> --release                    …back to the official releases
  creativecraft-cli updates [app] [--json] check for newer versions (releases, forks, git builds,
                                           and CreativeCraft itself) without installing anything
  creativecraft-cli remove <app>...        uninstall
  creativecraft-cli open <app> [files...]  open an app
  creativecraft-cli sync [--preview|--test] sync the projects folder with cloud storage (or show the
                                           plan, or just check the connection)
  creativecraft-cli login | logout         sign in to / out of Google Drive
  creativecraft-cli projects [--json]      recent files in the projects folder, newest first
  creativecraft-cli plugins                 Marketplace plugins and their state
  creativecraft-cli plugins install|remove|enable|disable <id>
  creativecraft-cli plugins refresh        fetch the newest plugin list
  creativecraft-cli stock search <words>    free public-domain photos, art, video, audio [--kind …]
  creativecraft-cli stock download <source> <id> [size]   into the projects folder's Stock/
  creativecraft-cli stock list [words]     what's downloaded, offline
  creativecraft-cli generate image <prompt>   make images with your AI service, into Generated/
                     [--provider id] [--model m] [--aspect square|landscape|portrait] [--count 1-4]
                     [--negative text] [--seed n]
                     [--image file]… start from a picture: edit or restyle it [--strength 1-100]
                     [--mask file]  change only the white part of the first picture
  creativecraft-cli generate video <prompt>   a short video [--seconds n] (and the options above;
                                           --image is the first frame)
  creativecraft-cli generate providers     your AI generation services
  creativecraft-cli generate presets       services you can add: OpenAI, Google, xAI, Replicate, fal,
                                           Together, ComfyUI, Stable Diffusion WebUI, custom
  creativecraft-cli generate add <preset> [--url u] [--image-model m] [--video-model m]
  creativecraft-cli generate key <id>      set its API key (read from standard input)
  creativecraft-cli generate remove|test <id>
  creativecraft-cli generate default image|video <id>
  creativecraft-cli bug [app]              report a bug in an app (or, with no app, in CreativeCraft)
  creativecraft-cli chat <message>         one AI chat turn (continues the current chat)
  creativecraft-cli chat --new             start a fresh chat
  creativecraft-cli agent-setup            one-time setup for the chat backend (Hermes)
  creativecraft-cli mcp                    serve MCP on stdio for AI assistants

Settings live in the config folder (settings.json). CREATIVECRAFT_HOME=<dir> keeps all data in one
folder. GITHUB_TOKEN raises GitHub's download-API rate limit.
